# Золотое Яблоко — AI-ассистент (интерактивный прототип)

Прототип собран по макету Figma
[11.08.26 🍏](https://www.figma.com/design/h0ShQ3o8k37L6Z33ZW1L31/11.08.26-%F0%9F%8D%8F?node-id=240-26765),
страница «Прототип». Макет — source of truth: токены, отступы, типографика и композиция
сняты напрямую из файла, иллюстрации и фото продуктов выгружены оттуда же.

## Запуск

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`. Вьюпорт — 375 × 812 (как в макете), на десктопе
телефон центрируется на подложке.

## Стек

React 18, TypeScript, Vite, Framer Motion. Иконки — собственные SVG-компоненты
(`src/components/Icons.tsx`), сторонние icon-пакеты не подключались.

## Демо-сценарий

Приложение открывается на «избранном». Основной путь проходится без подсказок:

1. плавающий баннер «спросить эксперта» → шторка знакомства;
2. онбординг: приоритеты → бюджет → что не подходит → продукты 24/7 → выбор оттенка;
3. чат: запрос про подарок → бюджет → предпочтения → рекомендации;
4. «почему подходит» → «показать источники» → «сравнить»;
5. карточка товара → в корзину → оформление;
6. профиль → «оценить покупку» → «не зашло» → причина → «Запомнила»;
7. профиль обновляется, следующая рекомендация учитывает новое ограничение.

Дополнительные сценарии из брифа:

| Сценарий | Как воспроизвести |
| --- | --- |
| A. AI не знает ответа | спросить в чате «какой SPF у этого крема в цифрах?» |
| B. Нет подходящего продукта | в рекомендациях выбрать «не подходит» |
| C. Нет доверия к AI | спросить «почему я должна тебе верить?» |
| D. Нужен человек | «позвать консультанта» — консультанту уходит контекст диалога |
| E. Продукт не понравился | профиль → «оценить покупку» → «не зашло» |

Точки входа в ассистента сохраняют контекст: избранное, поиск, шторка «поделиться»
и карточка товара (в PDP ассистент уже знает, какой продукт открыт).

## Структура

```
src/
  components/   переиспользуемые блоки: бабблы, пилюли, карточки, шторки, чром телефона
  screens/      экраны: онбординг, чат, магазин, PDP, шторки
  lib/          состояние (store), mock-движок ассистента (ai.ts), типы
  data/         продукты, источники
  styles/       токены, глобальные стили, стили экранов и компонентов
public/assets/  иллюстрации маскота и фото продуктов из макета
```

## Инструменты

`tools/` — вспомогательные скрипты: выгрузка данных и ассетов из Figma, нарезка
изображений (`slice-assets.mjs`) и автоматические прогоны для проверки качества.

```bash
node tools/shots.mjs    # скриншоты основного пути
node tools/qa-nav.mjs   # проверка навигации, шторок, скролла
node tools/qa-edge.mjs  # дополнительные сценарии A–E
```

Скриншотам нужен установленный Chrome и запущенный dev-сервер.
